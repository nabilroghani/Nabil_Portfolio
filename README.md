## 🛠️ Tech Stack & Architecture

- **Frontend & Serverless Backend:** Next.js 16 (App Router) with unified API Routes (`/api/*`)
- **Styling & UI:** Tailwind CSS, Lucide Icons, Custom Parallax & Interactive 3D Effects
- **Database:** MongoDB Atlas with Mongoose connection pooling
- **Media & Assets:** Cloudinary CDN for responsive high-res project showcases
- **Notifications & Email:** Nodemailer via Gmail SMTP SSL direct dispatch
- **Deployment:** Vercel Serverless Edge Infrastructure

---

## ✨ Key Features

- ⚡ **Full Stack App Router Architecture:** Integrated admin dashboard, analytics, CV download, and client message dispatch.
- 📱 **100% Fully Responsive:** Tailored experiences across mobile, tablet, and ultra-wide screens.
- 🌓 **Fluid Dark & Light Themes:** Instant toggle with hydration-safe client state persistence.
- 📊 **Interactive Admin Portal:** Manage live projects, technical skills/tools, client messages, and download CV.
- 🔍 **Enterprise SEO & AEO Ready:** Schema.org JSON-LD structured data, OpenGraph previews, automated XML sitemap, and AI engine crawlers integration.
